This page contains software projects developed for my research
in mathematical physics, graph theory, and quantum gravity.

## trivalent

**trivalent** is a Python package for studying trivalent
(3-regular) graphs embedded in two-dimensional surfaces.

The package provides tools for graph isomorphisms,
automorphism groups, face structures, and Pachner moves.
It also supports edge decorations, including orientations
and parity assignments, represented using bitmasks.

- [Documentation](https://dcartin.github.io/trivalent)
